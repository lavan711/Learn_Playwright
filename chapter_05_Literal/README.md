# Chapter 05: Literals

## Overview
Learn about different types of literals in JavaScript and how to represent values in your code.

## Topics Covered

- **22_Literal.js** - Introduction to literals in JavaScript
- **23_null_undefined.js** - Understanding null and undefined
- **24_null.js** - Deep dive into null values
- **25_Literal_All.js** - Comprehensive overview of all literal types
- **26_Literal_Number_All.js** - All numeric literal formats
- **27_String.js** - String literals and string basics
- **28_Template_Literal.js** - ES6 template literals and interpolation
- **29_Backtick_single_double.js** - Differences between backticks, single, and double quotes

## What You'll Learn

- **Literals Definition**: Fixed values that don't change in the code
- **Numeric Literals**: Integers, floats, exponential notation
- **String Literals**: Single quotes, double quotes, escape sequences
- **Template Literals**: Backticks and string interpolation
- **Special Values**: null and undefined
- **Boolean Literals**: true and false
- **Quote Comparison**: When to use different quote styles

## Key Concepts

### Types of Literals

1. **String Literals**
   - "double quoted string"
   - 'single quoted string'
   - `template literal with ${expression}`

2. **Numeric Literals**
   - Integers: 42, -10
   - Floats: 3.14, -0.5
   - Exponential: 1e5, 2E-3
   - Binary: 0b1010
   - Hexadecimal: 0xFF
   - Octal: 0o17

3. **Special Literals**
   - null (no value)
   - undefined (not yet assigned)
   - true / false (booleans)

4. **Template Literals**
   - Multi-line strings
   - String interpolation: `${variable}`
