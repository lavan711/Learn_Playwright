## Key Concepts

### Operator Categories

1. **Assignment**: =, +=, -=, *=, /=, %=, **=
2. **Arithmetic**: +, -, *, /, %, **
3. **Comparison**: ==, ===, !=, !==, <, >, <=, >=
4. **Logical**: &&, ||, !
5. **Unary**: ++, --, !, typeof
6. **Ternary**: condition ? true_value : false_value
7. **Special**: ??, ?., (nullish coalescing and optional chaining)

### Important Distinctions

- **== vs ===**: == performs type coercion, === checks type and value
- **++a vs a++**: Pre-increment returns new value, post-increment returns old value
- **&& vs ||**: AND and OR with short-circuit evaluation
