## Key Concepts

### If Statement Structure

```javascript
// Simple if
if (condition) {
  // code if true
}

// If/else
if (condition) {
  // code if true
} else {
  // code if false
}

// If/else if/else
if (condition1) {
  // code if condition1 true
} else if (condition2) {
  // code if condition2 true
} else {
  // code if all false
}
```
